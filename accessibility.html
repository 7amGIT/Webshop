Barrierefreiheitserklärung

DINGIR ist bemüht, seine Website im Einklang mit den Web Content Accessibility Guidelines (WCAG) 2.2 auf Konformitätsstufe AA barrierefrei zugänglich zu machen.

Stand der Vereinbarkeit

Diese Website ist teilweise konform mit den Anforderungen der WCAG 2.2 AA.

Umgesetzte Maßnahmen

  • Semantisches HTML (header, nav, main, footer)
  • Tastaturbedienbarkeit aller interaktiven Elemente
  • Ausreichende Farbkontraste
  • Beschriftete Formularelemente
  • Skip-Link zur Hauptnavigation
  • Berücksichtigung von prefers-reduced-motion

Testverfahren

Die Website wurde mit folgenden Tools überprüft:

  • WAVE Web Accessibility Evaluation Tool
  • axe DevTools
